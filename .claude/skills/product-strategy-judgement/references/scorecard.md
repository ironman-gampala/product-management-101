# Scorecard

Use after a mock or when reviewing a pasted answer. Be direct: the learner is deciding whether they
are ready for real loops, so a soft verdict wastes their time. Score what they did, not what they
did after a hint — note hints separately.

## 1. Weak-spot table (first)

If the learner profile lists weak spots, score each one:

| Weak spot | What happened today | Status |
|---|---|---|
| … | specific moment from the mock | 🟢 fixed / 🟡 improving / 🟠 half / 🔴 still there |

Then one line: **the big insight from today** — the single habit that caused most of the losses
(e.g. "you describe well but never close a door: principles, options and the call all stayed open").

## 2. Step scores (out of 10)

| Step | 4/10 looks like | 7/10 looks like (L4 pass) | 9/10 looks like (L5 strong) |
|---|---|---|---|
| Clarify | Feature questions, one at a time; no horizon or success set | Batched questions, horizon and success pinned, assumptions stated | A framing question that reveals a hypothesis and genuinely reshapes the option set |
| Business goals | Mission statement; no revenue model | Correct revenue model and growth stage | Names the tension between what the company says and how it earns, and uses it as the anchor |
| Landscape | "AI is disrupting everything"; feature comparison | Specific trigger, real competitors and their positioning | Says why now differs from 18 months ago, names threat models (distribution vs architecture); the interviewer learns something |
| Principles | Values ("trust", "innovation"); or skipped | Real, company-specific principles | Each one kills a named option; a tiebreaker drawn from the main tension |
| Options | One idea, or a list of 7 with no cuts | 4–5 ideas, a shortlist of ≤ 3 | Wide brainstorm across where-to-play and how-to-win, cuts made by name against principles, right to win tested |
| Argue & close | "It depends" or "a combination" | One clear call with reasons; holds when pushed | Connecting sentence, counter raised unprompted and defeated, first move, counter-metric, change-my-mind signal |
| Communication | Filler, "so yeah", drifts between steps | Clear, mostly signposted | Calm, drives the room, the chain from business to call is said out loud, crisp summary |

For GTM, growth and pricing, read the steps through `subtypes.md` (e.g. "Business goals" includes
the growth equation; "Argue & close" includes a specific price or a sequenced launch).

Give each step a score, one "what landed" and one "what to fix".

## 3. Rubric read — the five dimensions

The repo's rubric (`Product Strategy/Rubric for Product Strategy Interviews.md`) scores five equal
dimensions on Strong No Hire / No Hire / Hire / Strong Hire. Give each one a rating and one line of
evidence:

| Dimension | Rating | Evidence from this answer |
|---|---|---|
| Business model fluency | | |
| Landscape accuracy | | |
| Decision quality | | |
| Structural clarity | | |
| Genuine POV | | |

All five carry equal weight: acing three and failing two is not a hire. For Genuine POV, run the
five-candidates test out loud — "could five other prepared candidates have said this?" — and quote
the one line that was theirs alone, or say there wasn't one.

## 4. Overall level read

| Overall | Read |
|---|---|
| ≤ 5 | Below PM2 bar. Interviewer had to drive; no real call made. |
| 6 | Borderline L4. Structure is there; principles and close are soft. |
| 7 | L4 / PM2 pass. Clear call, defended when pushed; landscape or principles generic. |
| 8 | Strong L4, borderline L5. Principles kill options; counter named but defeated thinly. |
| 9+ | L5 / Senior pass. Business tension drives the answer, counter raised and defeated unprompted, memorable POV. |

State the verdict for each target level the learner is interviewing for (e.g. "PM2: pass. Senior:
lean reject."), with the reason in one sentence each. Strategy is where L5 is decided, so say
plainly which step held them below it.

## 5. Fix the weakest step

Write the model turn for the weakest step only — spoken, first person, full sentences, for this
same question — so they leave with one thing to rehearse rather than a pile of notes.

## 6. Drill plan

Three short daily drills, each mapped to a weak spot. Pick from these defaults or write your own:
- **Follow the money in 60 seconds:** any company → where the money comes from, where it's
  investing, the one-sentence tension.
- **Principle that kills:** any strategy prompt → write two "we won't ___ because ___, which rules
  out ___" sentences.
- **Steelman and defeat:** take yesterday's recommendation → say the strongest case against it,
  concede one point, defeat it in three sentences.
- **Move teardown (10 min):** one real company move from the news → the five teardown questions →
  one written opinion.

## 7. Log it

If `my-profile/` exists, log the session in `my-profile/daily-practice/`: a new day file plus updates to
`daily-practice.md` (see SKILL.md → Learner profile). With an older single `My Profile.md`, append a mock log row: date | question | type | score | key notes.
If it doesn't, offer once to create it by copying the `my-profile-template/` folder to `my-profile/` with today's weak spots filled in.
